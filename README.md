# php-Team-Classroom-Material-Sharing-System
ชื่อทีม :What is it?
ชื่อโครงงาน :ระบบประกาศแบ่งปันและยืมอุปกรณ์ระหว่างห้องเรียน (Classroom Material Sharing System) 
ปัญหาที่จะแก้ :นักศึกษาและครูมักเจอปัญหาอุปกรณ์เหลือทิ้งจากการทำโครงงาน (เช่น สายไฟ บอร์ดไมโครคอนโทรลเลอร์ เซนเซอร์ หรือเครื่องมือช่าง) ในขณะที่นักศึกษากลุ่มอื่นต้องการใช้ชั่วคราวแต่ไม่ทราบว่าห้องไหนมี ทำให้ต้องเสียเงินซื้อใหม่ เกิดความสิ้นเปลืองและเป็นขยะสะสม ปัญหานี้เกิดขึ้นบ่อยโดยเฉพาะช่วงปลายเทอมที่มีการทำโปรเจกต์ 
ผู้ใช่ระบบ :นักศึกษา เจ้าหน้าที่ห้องปฏิบัติการ/ครู
